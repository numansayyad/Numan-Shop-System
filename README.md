# 🛍️ Numan Shop System

A simple and smart shopping system made using Python. 💻  
This program allows users to buy products from different sections like **Electronics**, **Grocery**, and more.  
It also calculates **discounts automatically** based on the total bill amount. 💰  

---

## ✨ Features
- 🏪 Select from multiple product sections  
- 💸 Automatic discount calculation  
- 📦 Check product prices and total cost  
- 👨‍💻 Beginner-friendly Python code  
- 🧾 Final bill generation  

---

## 🧭 How to Run
1. Open the file **`numan_shop_system.py`** in any Python IDE (like VS Code or IDLE).  
2. Run the program.  
3. Choose your section and products.  
4. Enter quantity and check your final bill with discounts.  

---

## 💡 Technologies Used
- **Python 🐍**  
- Basic concepts: `if-elif-else` and `input()`
